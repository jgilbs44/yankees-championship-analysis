## Yankees-championship-analysis
Comparing Yankees batting statistics across five World Series championship seasons using Python.

For this project, I scraped regular season batting statistics from Wikipedia for the Yankees' 1996, 1998, 1999, 2000, and 2009 seasons. I used pandas to clean and analyze hits, home runs, and RBIs, answered five questions, and created two graphs using Seaborn.

## Files

- Gilby_Project2_Part2.ipynb: My notebook with the web scraping, data cleaning, analysis, graphs, and conclusions.
- README.md: A description of the project, files, and data sources.
